# FairMOT Tracking Usage Guide

## Overview

This document explains how to use FairMOT for multi-object tracking evaluation. FairMOT now supports both traditional MOT evaluation and ByteTrack-style half-split evaluation in a unified interface.

## Environment Setup

### Dataset Path Configuration

FairMOT supports multiple ways to configure dataset paths:

```bash
# Recommended: Use general environment variable
export DATA_ROOT=/path/to/your/datasets

# Legacy FairMOT compatibility
export FAIRMOT_DATA_ROOT=/path/to/your/datasets

# ByteTrack compatibility
export YOLOX_DATADIR=/path/to/your/datasets
```

If no environment variable is set, the system will automatically use the `datasets/` folder in the project root directory.

## Dataset Structure

Make sure your dataset is organized according to the following structure:

```
datasets/
├── MOT20/
│   ├── train/
│   │   ├── MOT20-01/
│   │   │   ├── img1/
│   │   │   ├── gt/
│   │   │   │   ├── gt.txt (original)
│   │   │   │   ├── gt_train_half.txt (first half, generated by ByteTrack)
│   │   │   │   └── gt_val_half.txt (second half, generated by ByteTrack)
│   │   │   └── det/
│   │   │       ├── det.txt (original)
│   │   │       ├── det_train_half.txt (first half, optional)
│   │   │       └── det_val_half.txt (second half, optional)
│   │   ├── MOT20-02/
│   │   └── ...
│   └── test/
│       ├── MOT20-04/
│       ├── MOT20-06/
│       └── ...
└── MOT17/
    ├── train/
    └── test/
```

## Quick Start

### Basic Usage

```bash
# Traditional validation set evaluation
python scripts/track.py --dataset MOT20 --split val --load_model ./models/mot20_fairmot.pth

# ByteTrack-style half split evaluation  
python scripts/track.py --dataset MOT20 --split train_half --load_model ./models/mot20_fairmot.pth
python scripts/track.py --dataset MOT20 --split val_half --load_model ./models/mot20_fairmot.pth
```

### Help Information

```bash
python scripts/track.py --help
```

## Evaluation Modes

### 1. Traditional MOT Evaluation

**Validation Set (with ground truth for evaluation)**
```bash
# MOT20 validation set (MOT20-01, MOT20-02, MOT20-03, MOT20-05)
python scripts/track.py --dataset MOT20 --split val --load_model ./models/mot20_fairmot.pth

# MOT17 validation set
python scripts/track.py --dataset MOT17 --split val --load_model ./models/fairmot_dla34.pth

# MOT16 validation set  
python scripts/track.py --dataset MOT16 --split val --load_model ./models/fairmot_dla34.pth
```

**Test Set (no ground truth, for competition submission)**
```bash
# MOT20 test set (MOT20-04, MOT20-06, MOT20-07, MOT20-08)
python scripts/track.py --dataset MOT20 --split test --load_model ./models/mot20_fairmot.pth

# MOT17 test set
python scripts/track.py --dataset MOT17 --split test --load_model ./models/fairmot_dla34.pth
```

### 2. ByteTrack-Style Half-Split Evaluation

This evaluation method splits each training sequence into two halves, enabling training on the first half and validation on the second half.

**Train Half (first half of each sequence)**
```bash
python scripts/track.py --dataset MOT20 --split train_half --load_model ./models/mot20_fairmot.pth
```

**Val Half (second half of each sequence)**
```bash
python scripts/track.py --dataset MOT20 --split val_half --load_model ./models/mot20_fairmot.pth
```

**Prerequisites for Half-Split Evaluation:**
- Ground truth files `gt_train_half.txt` and `gt_val_half.txt` must exist
- These are generated by ByteTrack's conversion script `convert_mot20_to_coco.py`

## Advanced Usage

### Custom Sequence Selection

```bash
# Evaluate specific sequences only
python scripts/track.py --dataset MOT20 --split val --seqs MOT20-01,MOT20-02 --load_model ./models/mot20_fairmot.pth

# Half-split on specific sequences
python scripts/track.py --dataset MOT20 --split train_half --seqs MOT20-01 --load_model ./models/mot20_fairmot.pth
```

### Device Configuration

```bash
# Automatic device selection (default)
python scripts/track.py --dataset MOT20 --split val --device auto --load_model ./models/mot20_fairmot.pth

# Force CPU mode
python scripts/track.py --dataset MOT20 --split val --device cpu --load_model ./models/mot20_fairmot.pth

# Specific GPU
python scripts/track.py --dataset MOT20 --split val --device cuda:0 --load_model ./models/mot20_fairmot.pth
```

### Tracking Parameter Tuning

```bash
# Higher detection confidence to reduce false positives
python scripts/track.py --dataset MOT20 --split val --conf_thres 0.6 --load_model ./models/mot20_fairmot.pth

# Longer tracking buffer for fast-moving targets
python scripts/track.py --dataset MOT20 --split val --track_buffer 50 --load_model ./models/mot20_fairmot.pth

# Larger minimum detection box area to filter small targets
python scripts/track.py --dataset MOT20 --split val --min_box_area 500 --load_model ./models/mot20_fairmot.pth
```

### Output Options

```bash
# Save tracking videos
python scripts/track.py --dataset MOT20 --split val --save_videos --load_model ./models/mot20_fairmot.pth

# Save individual frame images
python scripts/track.py --dataset MOT20 --split val --save_images --load_model ./models/mot20_fairmot.pth

# Custom experiment ID
python scripts/track.py --dataset MOT20 --split val --exp_id my_experiment --load_model ./models/mot20_fairmot.pth
```

## Parameters Reference

| Parameter | Description | Default | Example |
|-----------|-------------|---------|---------|
| `--dataset` | Dataset name | MOT16 | MOT15, MOT16, MOT17, MOT20, MOT20_mini |
| `--split` | Dataset split | val | train, val, test, train_half, val_half |
| `--load_model` | Pre-trained model path | Auto-detect | ./models/mot20_fairmot.pth |
| `--seqs` | Comma-separated sequence names | All sequences | MOT20-01,MOT20-02 |
| `--data_dir` | Dataset root directory | datasets | /path/to/datasets |
| `--device` | Device to use | auto | cpu, cuda, cuda:0, auto |
| `--conf_thres` | Detection confidence threshold | 0.4 | 0.3-0.7 |
| `--det_thres` | Detection threshold | 0.3 | 0.2-0.5 |
| `--nms_thres` | NMS threshold | 0.4 | 0.3-0.6 |
| `--track_buffer` | Tracking buffer size | 30 | 10-100 |
| `--min_box_area` | Minimum detection box area | 100 | 50-1000 |
| `--exp_id` | Experiment ID | default | my_experiment |
| `--save_videos` | Save output videos | False | Flag |
| `--save_images` | Save individual frames | False | Flag |

### Output Format

Each `.txt` file contains tracking results in MOT format:
```
<frame_id>,<track_id>,<x>,<y>,<width>,<height>,1,-1,-1,-1
```

## Evaluation Metrics

The script automatically calculates standard MOT metrics:

- **MOTA** (Multiple Object Tracking Accuracy)
- **MOTP** (Multiple Object Tracking Precision)  
- **IDF1** (ID F1 Score)
- **IDs** (Identity Switches)
- **Frag** (Fragmentations)
- **FP** (False Positives)
- **FN** (False Negatives)

Results are displayed in the terminal and saved as Excel files.

## ByteTrack Integration

### Data Preparation

To use half-split evaluation, you need ground truth files generated by ByteTrack:

1. Download and set up ByteTrack
2. Run ByteTrack's data conversion:
   ```bash
   cd /path/to/ByteTrack
   python tools/convert_mot20_to_coco.py
   ```
3. This generates `gt_train_half.txt` and `gt_val_half.txt` files

### Half-Split Workflow

```bash
# 1. Evaluate on training half (for debugging/validation during training)
python scripts/track.py --dataset MOT20 --split train_half --load_model ./models/mot20_fairmot.pth

# 2. Evaluate on validation half (for hyperparameter tuning)
python scripts/track.py --dataset MOT20 --split val_half --load_model ./models/mot20_fairmot.pth

# 3. Compare with traditional validation
python scripts/track.py --dataset MOT20 --split val --load_model ./models/mot20_fairmot.pth
```

## Troubleshooting

### Common Issues

**1. Missing Ground Truth Files**
```
No ground truth found for MOT20-01 train_half - ensure ByteTrack conversion was run
```
**Solution**: Run ByteTrack's `convert_mot20_to_coco.py` to generate half-split ground truth files.

**2. Model Not Found**
```
Warning: No model specified and default model not found
```
**Solution**: Download the required model file or specify the path with `--load_model`.

**3. CUDA Out of Memory**
**Solution**: Use `--device cpu` or reduce input resolution.

**4. Dataset Path Error**
```
AssertionError: No images found in datasets/MOT20/train/MOT20-01/img1
```
**Solution**: Check dataset path and structure, or use `--data_dir` to specify the correct path.

### Debug Mode

```bash
# Verbose output for debugging
python scripts/track.py --dataset MOT20 --split val --load_model ./models/mot20_fairmot.pth -v
```
